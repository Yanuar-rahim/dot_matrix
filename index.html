Mengenal Dot Matrix 8×8

Mengendalikan LED Dot Matrix MAX7219 dengan Arduino Uno menggunakan library MD_MAX72XX dan MD_Parola.

Tujuan pembelajaran. Menjelaskan prinsip Dot Matrix, mengidentifikasi pin MAX7219, merangkai modul, menginstal library, dan memodifikasi program untuk menghasilkan pola LED.

Apa itu Dot Matrix?

Dot Matrix adalah tampilan elektronik yang tersusun dari titik-titik LED dalam baris dan kolom. Setiap titik adalah satu LED yang dapat diatur menyala atau mati.

Modul yang umum dipakai dalam praktikum berukuran 8×8: 8 baris dan 8 kolom, total 64 LED. Dengan mengatur kombinasinya, kita dapat membentuk pola, simbol, angka, hingga huruf.

  • 64 titik LED: delapan baris dikali delapan kolom.
  • Kontrol digital: Arduino mengirim instruksi lewat library MD_MAX72XX atau MD_Parola.
  • Tampilan fleksibel: ikon, animasi sederhana, dan teks berjalan.
  • Hemat pin: MAX7219 memakai antarmuka serial sehingga pemrogramannya lebih mudah.

Contoh penggunaan

Jam digital, papan informasi mini, indikator status perangkat, penghitung skor, dan proyek animasi LED.

Bagaimana Dot Matrix bekerja?

LED disusun dalam baris dan kolom. Pengendali memilih kombinasi baris dan kolom untuk mengaktifkan titik tertentu. Pola nyala inilah yang membentuk gambar atau karakter.

Untuk membuat simbol hati, program menyimpan pola 8 baris. Setiap baris berisi delapan bit: 1 berarti LED menyala dan 0 berarti mati. Pemetaan persisnya dapat bergantung pada orientasi dan konfigurasi modul.

Catatan. Modul Dot Matrix telanjang membutuhkan rangkaian pengendali dan teknik multiplexing. Untuk pemula, modul yang sudah dilengkapi MAX7219 lebih mudah digunakan.

Mengenal modul MAX7219

MAX7219 adalah IC driver display untuk LED, termasuk Dot Matrix 8×8. IC ini mengatur pengendalian LED sehingga Arduino cukup mengirim data melalui antarmuka serial.

Pin modul Fungsi
VCC Catu daya positif, umumnya 5V pada modul Arduino.
GND Ground atau jalur negatif.
DIN Data masuk dari Arduino.
CS / LOAD Pemilih perangkat dan latch data.
CLK Clock untuk sinkronisasi pengiriman data.
Perhatikan. Pastikan modul memang memiliki IC MAX7219, dan periksa label pin serta jenis susunan modul (misalnya FC-16) pada PCB. Jangan menghubungkan VCC secara sembarang jika spesifikasi modul berbeda.

Menghubungkan ke Arduino Uno

Pemetaan berikut untuk satu modul MAX7219 dengan software SPI. Hubungkan kabel saat Arduino tidak sedang diberi daya.

MAX7219 Arduino Uno Keterangan
VCC 5V Catu daya
GND GND Ground
DIN D12 Data
CS / LOAD D10 Chip select
CLK D11 Clock
Pin D12, D11, dan D10 adalah konfigurasi yang dipakai pada kode di materi ini. Jika pin diubah, sesuaikan juga parameter pada program.

Instalasi MD_Parola dan MD_MAX72XX

  • MD_MAX72XX: library tingkat rendah untuk mengendalikan LED Matrix MAX7219/MAX7221 (titik, baris, kolom, intensitas).
  • MD_Parola: library tingkat tinggi di atas MD_MAX72XX untuk teks, posisi, teks berjalan, dan efek animasi.
Hubungan keduanya. MD_Parola membutuhkan MD_MAX72XX. Instal keduanya.

Langkah instalasi di Arduino IDE

  1. Buka Arduino IDE.
  2. Pilih Sketch → Include Library → Manage Libraries.
  3. Cari MD_MAX72XX dari MajicDesigns, lalu Install.
  4. Cari MD_Parola dari MajicDesigns, lalu Install.
  5. Pilih board Arduino Uno dan port yang benar di menu Tools.

Menentukan jenis modul

Contoh program memakai modul FC-16 (panel 4-in-1). Jika modul Anda berbeda, sesuaikan tipe hardware dengan tulisan pada PCB.

MD_MAX72XX::PAROLA_HW Modul Parola.
MD_MAX72XX::GENERIC_HW Modul generic.
MD_MAX72XX::ICSTATION_HW Modul ICStation.

Menggunakan MD_Parola dan MD_MAX72XX

Ubah MAX_DEVICES menjadi 1 untuk satu modul, atau 4 untuk panel 4-in-1. Nilai ini adalah jumlah modul 8×8 yang dirangkai berantai, bukan jumlah LED.
